# Skill — Landkarte anlegen (eigene Navigations-Landkarte der Agentur)

STATUS: ANLEITUNG (Skill — kein Gesetz; bewusst ohne _Kanon.md-Endung, Qualifikation als Präfix)
ZWECK: Die neue Instanz/Agentur der Zielumgebung legt sich ihre EIGENE Landkarte an — das Paket liefert bewusst KEINE gefüllte Landkarte, sondern nur dieses Verfahren. Die Landkarte ist Navigation ohne Migration: Sie zeigt je Regel/Verfahren den kanonischen Ort auf einen Blick.
KONNEKTIVITÄT:
BENÖTIGT: dauerhafte Wissens-Ablage (Schreibzugriff auf EINE eigene Landkarten-Datei) · Such-Instrument optional (ohne es: volle Lektüre, mit Kennzeichnung des Mehraufwands)
FEHLT Ablage: Landkarte nicht führbar → Fundmeldung über den Auftragskanal; keine Ersatz-Struktur in Gesprächs-Verläufen (Chat ist Transport, Ablage ist Speicher).

## Schrittfolge

1. **Anlage:** EINE Datei als Navigations-Index in der Wissens-Ablage anlegen (z. B. `Landkarte.md`). Struktur: Tabelle mit den Spalten *Regel/Verfahren · kanonischer Ort (Datei) · Status*.
2. **Eintragen je Paket-Datei:** kanonischer Ort = die jeweilige Paket-Datei (`<Name>_Kanon.md` für Gesetze; `Skill_`/`Verzeichnis_`/`Adapter_`-Dateien mit Qualifikations-Vermerk). Die Landkarte VERWEIST nur — sie dupliziert keine Regeltexte (eine Wahrheit genau einmal).
3. **Status-Spalte führen** (KANONISCH/ENTWURF, aus dem Datei-Kopf): Die Datei ist führend, die Landkarte ist Pflicht-Nachtrag, kein zweiter Gesetzgeber — bei Widerspruch gewinnt die Datei.
4. **Lücken sichtbar markieren:** Nicht auffindbares (Verfahren ohne kanonischen Ort, fehlende Datei) = LÜCKE → Fundmeldung über den Auftragskanal statt Improvisation.
5. **Pflege:** Jede Kanon-Orts-Änderung (neue Datei, neue Version, Status-Wechsel) erhält eine Nachtrags-Zeile; neue Datei = neue Zeile (append-only); Bestandszeilen nicht still umschreiben. „Weg" heißt beweisgesichert archiviert, nie löschen.
6. **Instanz-Start:** Jede neue Instanz liest die Landkarte als Schritt 0 (Wissens-Lektüre vor jedem Auftrag) und prüft unbekannte Verweise gegen den Stand (bekannter Stand + unbekannter Ort = Lücke → Fundmeldung).

## Beweis-Artefakt

Die Landkarte selbst: Tabelle mit je Regel/Verfahren kanonischem Ort + Status + Pflege-Vermerk (Datum, gemessen). Nachweis der Pflege-Treue: Nachtrags-Zeilen je Kanon-Änderung (append-only, mit Mess-Stempel).

## Grenzen

- Die Landkarte bewertet nicht, sie verweist nur.
- Keine Regeltexte in der Landkarte (Duplikat-Verbot).
- Verwaiste Verweise (Ort existiert nicht mehr) = Lücke → Fundmeldung; niemals still entfernen, sondern archivieren.
